# واژگانِ برچسب — عمه‌جان

هر شخصیت **یک خط** است، دقیقاً با چهار ستون که با `|` جدا می‌شوند:

```
'نام|توضیح کوتاه|رده|برچسب‌ها'
```

- **نام** — همان‌طور که یک فارسی‌زبان می‌نویسد و تلفظ می‌کند («دین وینچستر»، «والتر وایت»، «کریتوس»).
- **توضیح** — دو تا چهار کلمه، شناسه‌ی کوتاه که در صفحه‌ی حدس دیده می‌شود («شکارچیِ شیاطین»، «معلمِ شیمی»). هرگز `—` نگذار.
- **رده** — ۴ تا ۱:
  - `4` اسمش را تقریباً همه شنیده‌اند، حتی کسی که اهلِ آن دنیا نیست (ماریو، هری پاتر، جوکر).
  - `3` خیلی‌ها می‌شناسندش؛ هر کسی که فیلم/سریال/بازی دنبال می‌کند (والتر وایت، کریتوس، شرلوک).
  - `2` نیمه‌معروف؛ فقط اهلِ همان حوزه (وسپر لیند، الکساندر ماهون، وجیتا).
  - `1` خاص‌پسند و گوشه‌ای.
- **برچسب‌ها** — با `,` و بدون فاصله‌ی اضافه. **حداقل ۷ برچسب.** فقط از فهرستِ زیر.

نقلِ قول را `'` بگذار و اگر در نام `'` بود با `\'` فرار بده.

---

## ۱) پایه (تقریباً همیشه لازم)

| برچسب | یعنی |
|---|---|
| `m` / `f` | مرد / زن. اگر جنسیت ندارد (ربات، حیوان، گروه) هیچ‌کدام را نگذار. |
| `fic` | شخصیتِ خیالی است. **هر شخصیتِ فیلم/سریال/بازی/کارتون `fic` می‌گیرد.** |
| `alive` / `dead` | فقط برای آدم‌های واقعی. |
| `ir` `us` `eu` `asia` | خاستگاهِ اثر یا شخص. یکی را حتماً بگذار. |

## ۲) رسانه — کجا دیدیش
`cinema` سینما · `series` سریال · `tv` تلویزیون · `game` بازیِ کامپیوتری/موبایلی ·
`cartoon` کارتون/انیمیشن · `anime` انیمه‌ی ژاپنی · `book` از کتاب آمده ·
`novelchar` شخصیتِ رمان · `puppet` عروسک · `theater` تئاتر · `internet` معروفِ اینترنت ·
`kids` بچه‌ها هم می‌شناسندش · `stadium` در ورزشگاه

## ۳) دوره
`ancient` صدها سال پیش · `old` قدیمی · `prerev` قبل از انقلاب · `d60` دهه‌ی شصت و هفتادِ شمسی ·
`modern` امروزی · `active` هنوز ادامه دارد / تازگی دیده شده · `newgen` تازه‌کار ·
`legend` اسطوره و ماندگار · `retro` **مالِ نسلِ اولِ بازی‌ها و کارتون‌ها (آتاری، سگا، نینتندوی قدیم، دهه‌ی ۸۰ میلادی)**

## ۸) حال‌وهوا
`comedy` طنز · `serious` جدی · `love` عاشقانه · `pop` · `traditional` · `classical` ·
`controversial` حاشیه‌دار · `beloved` محبوب · `rich` پولدار ·

## قاعده‌های کیفیت (این‌ها بازی را می‌سازند یا خراب می‌کنند)

1. **هیچ دو شخصیتی نباید برچسب‌های یکسان داشته باشند.** اگر دو نفر از یک سریال‌اند، چیزی که واقعاً فرق‌شان می‌کند را برچسب بزن: یکی `lead` است و دیگری نه؛ یکی `villain` است؛ یکی `f` است؛ یکی `beard` دارد؛ یکی `cop` است و دیگری `criminal`. اگر نتوانستی دو نفر را با برچسب از هم جدا کنی، یکی‌شان را ننویس.
2. **ظاهر را واقعاً نگاه کن.** `beard` `bald` `blond` `chubby` `glasses` `masked` ارزان‌ترین و قوی‌ترین برچسب‌های تفکیک‌کننده‌اند — هر جا درست است بگذار.
3. **رده را دستِ بالا نگیر.** رده‌ی ۴ فقط برای غول‌ها. اگر شک داری، یکی پایین‌تر.
4. برچسبی که در فهرست نیست ننویس. اگر چیزی کم داشتی، با برچسب‌های موجود نزدیک‌ترین را بساز.
5. برای هر شخصیتِ خیالی، `fic` + رسانه + خاستگاه + سرشت را حتماً بگذار.

## ۱۰) فیلم و انیمیشن به‌عنوانِ جواب (تازه)

وقتی جوابِ بازی **خودِ فیلم/انیمیشن** است (نه یک شخصیت یا بازیگر):

- برچسبِ `film` را بگذار و **`fic` و `m`/`f` و `alive`/`dead` را نگذار.**
- خاستگاه (`ir` `us` `eu` `asia`) الزامی است.
- `cinema` لازم نیست (خودکار است). برای انیمیشن `cartoon` (و برای انیمه‌ی ژاپنی `anime`).
- نام همان اسمی است که ایرانی‌ها می‌گویند («تایتانیک»، «جدایی نادر از سیمین»، «شیرشاه»).
  اگر یک شخصیت هم همین اسم را دارد (شرک، علاءالدین) اشکالی ندارد — فیلم جداگانه ذخیره می‌شود. توضیحِ فیلم را طوری بنویس که روشن باشد فیلم است («انیمیشنِ دریم‌ورکس»، «فیلمِ جیمز کامرون»).
- برای مجموعه‌ها یک ردیف کافی است («هری پاتر» نه هشت ردیف)، مگر قسمت‌ها واقعاً فرق دارند و جدا معروف‌اند.
- حال‌وهوا از همان برچسب‌های قبلی: `comedy` `love` `horror` `space` `fantasy` `apoc` `kids` `award` (اسکار/کن) `book` (از روی کتاب) `worldfame` `beloved` `legend` `prerev` `d60` `newgen` `ancient` (قصه در دورانِ باستان) `religious` `robot` `monster` `masked` `sword` `cop` `stream` (نتفلیکس/شبکه‌ی خانگی).

| برچسبِ فیلم | یعنی |
|---|---|
| `action` | پر از اکشن، تعقیب و گریز، انفجار |
| `scifi` | علمی‌تخیلی، آینده، تکنولوژی، آدم‌فضایی |
| `truestory` | از روی ماجرای واقعی |
| `sequel` | قسمتِ دوم و سوم دارد |
| `sadend` | پایانِ غمگین؛ آدم گریه‌اش می‌گیرد |
| `crime` | دزدی، جنایت، مافیا |
| `warfilm` | درباره‌ی جنگ |
| `musical` | آهنگ‌هایش معروف است / آواز می‌خوانند |
| `animals` | شخصیت‌های اصلی حیوان‌اند |
| `femlead` | قهرمانِ اصلی زن یا دختر است |
| `kidlead` | قهرمانِ اصلی بچه یا نوجوان است |
| `superhero` | ابرقهرمانی |
| `pre2000` | ساخته‌ی قبل از ۲۰۰۰ |
| `twist` | پایانِ غافلگیرکننده |
| `sea` | دریا، زیرِ آب، کشتی |
| `school` | مدرسه یا دانشگاه |
| `royal` | شاه، ملکه، شاهزاده، قصر |
| `sport` | درباره‌ی ورزش و مسابقه |
| `prison` | زندان یا فرار |
| `mindbend` | خواب، ذهن، سفر در زمان |
| `family` | دعوا و گرفتاری‌های یک خانواده |
| `village` | روستا یا شهرستان |
| `road` | سفر و جاده |

هر فیلم **حداقل ۷ برچسب** و باید از فیلم‌های هم‌رده‌اش با برچسب جدا شود.

## ۱۱) برچسب‌های داغ `fr_*` (تازه — مهم‌ترین بخشِ حسِ بازی)

این‌ها «دنیا» یا «گروهِ کوچک» را نام می‌برند. عمه فقط وقتی بو برده می‌پرسدشان
(«نکنه تو دنیای هری پاتره؟») و همین لحظه‌ی هیجانِ بازی است. **هر جا درست است
حتماً بگذار** — روی شخصیت، آدمِ واقعی و فیلم هر سه. چندتا با هم مجاز است
(مسی: `fr_barca,fr_fifa`؛ علی دایی: `fr_persepolis,fr_teammelli`).

فهرستِ کاملِ مجاز در `hot-questions.js` است. خلاصه:

- خارجی: `fr_marvel` `fr_dc` `fr_starwars` `fr_hp` `fr_lotr` `fr_got` `fr_disney` (دیزنی+پیکسار) `fr_dreamworks` `fr_ghibli` `fr_looney` (لونی‌تونز+هانا باربرا+تام و جری) `fr_simpsons` `fr_friends` `fr_bb` `fr_godfather` `fr_bond` `fr_stranger` `fr_moneyheist` `fr_prisonbreak` `fr_walkingdead` `fr_peaky` `fr_sherlock` `fr_pirates` `fr_matrix` `fr_jurassic` `fr_fast` `fr_toystory` `fr_shrek` `fr_iceage` `fr_madagascar` `fr_kungfu` `fr_frozen` `fr_lionking` `fr_minions` `fr_turtles` `fr_transformers`
- انیمه: `fr_pokemon` `fr_dbz` `fr_naruto` `fr_onepiece` `fr_aot` `fr_deathnote` `fr_demonslayer` `fr_captainmajid`
- بازی: `fr_mario` `fr_zelda` `fr_sonic` `fr_mk` `fr_sf` `fr_tekken` `fr_gta` `fr_cod` `fr_re` `fr_tlou` `fr_witcher` `fr_gow` `fr_mgs` `fr_ff` `fr_moba` `fr_clash` `fr_overwatch` `fr_valorant` `fr_halo` `fr_assassin` `fr_crash` `fr_fifa` (فوتبالیستِ معروفی که همه در فیفا/PES دیده‌اند)
- ایرانی: `fr_paytakht` `fr_barareh` `fr_modiri` (هر کارِ مهران مدیری، بازیگرانِ ثابتش هم) `fr_kolah` `fr_shahnameh` `fr_1001` `fr_khaneh` (سریال‌های خانوادگیِ دهه‌ی ۷۰/۸۰) `fr_ekhrajiha` `fr_mokhtar` (سریال‌های تاریخی‌مذهبی) `fr_ghahveh` `fr_shahrzad` `fr_zirkhaki` (سریال‌های پلیسی‌امنیتی) `fr_kidtv` (برنامه‌ی کودک)
- آدم‌های واقعی: `fr_persepolis` `fr_esteghlal` `fr_teammelli` (هر ورزشی) `fr_realmadrid` `fr_barca` `fr_england` `fr_basket` `fr_volley` `fr_fight` (بوکس/UFC/رزمی) `fr_race` `fr_tennis` `fr_olympic` (طلای المپیک) `fr_la` (خواننده‌ی ایرانیِ خارج‌نشین) `fr_rap` `fr_rock` `fr_kpop` `fr_band` `fr_standup` `fr_youtube` `fr_nobel` `fr_oscar` `fr_iranking` (شاهان ایران) `fr_prophet` `fr_classicpoet` `fr_dubbing`

برچسبِ `fr_` که در این فهرست نیست ننویس.
